How these numbers are measured
  • A small Python script reads every .java file; comments and string literals are blanked out before anything is counted.
  • A comment line holds only a comment; a line with code and a trailing comment counts as code.
  • A method is a declaration followed by a block; its length runs from the opening to the closing brace line.
  • A method that contains an anonymous class (the SAX handler in XdxfHelper.parseXdxf) also counts that class's branches, and the class's own methods are listed as well.
  • The numbers are approximate: close to what a dedicated tool reports, not identical.
